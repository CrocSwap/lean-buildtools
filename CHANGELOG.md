# Changelog

## 0.2.0

- Generic named SSH remotes with private job directories, source/input syncing,
  requested artifact collection, configurable caps and optional lease hooks.
- Serial `profile-batch` compilation with one remote sync and lease, per-member
  source snapshots, source-root routing and fail-fast product cleanup.
- Transitive axiom audits of compiled proof bodies, including private imports,
  cached-summary comparisons, dependency paths and stable artifact fingerprints.
- Exact caller refresh plans within selected headline roots, source hashes,
  ordered complete output prefixes and a final audit after selective rebuilding.
- Optional experimental `native-proof-tools` Lean package with explicitly
  registered rules, selected simplification, bounded cases and supplied-invariant
  equality transport. No general symbolic executor or demonstrated effort saving.
- Explicit compiler thread caps, compiler argument forwarding and local transport
  boundary tests.
- RSS projection starts at declaration elaboration; the hard RSS threshold
  remains active during imports. Handle already-exited compiler signal races.
- Include final flushed command events in child RSS and completion summaries.

## 0.1.0

- Initial alpha for Lean 4.35.0 on macOS and Linux.
- Audited compiler caps, RSS trend stops, and declaration profiles.
- Experimental compile-checked splits and import reductions.
- User-owned plugin cache and installable Python distributions.
- Optional strict proof/dependency policies, guarded source writes, and
  interrupted-report recovery.
- Self-contained tutorial and a small installed-package CI matrix.
